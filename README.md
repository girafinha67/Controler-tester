# LED Controle
App Android (12+) para controlar o LED RGB de controles, com cor fixa permanente e RGB em loop infinito.

1. Suba esta pasta inteira (com a pasta oculta .github) para um repositório novo no GitHub.
2. Aba Actions > "Build APK" > Run workflow (ou espere o push rodar sozinho).
3. Quando terminar, baixe o artefato "LedControle-apk", extraia e instale o app-debug.apk.
